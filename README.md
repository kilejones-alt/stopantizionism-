# STOPAZ Modern Institute Rebuild

Static GitHub Pages package rebuilt around an institutional research-and-education system.

## Deploy

Upload every file in this folder to the repository root. Keep all image, audio, HTML, CSS, JavaScript, icon, and `.nojekyll` files together at the root. In GitHub Settings → Pages, deploy from the repository branch and root directory. After deployment, hard-refresh the site.

## Structure

Primary navigation: About, Research, Education, Declaration, Exhibition. Secondary pages remain available from the footer. The Exhibition retains a separate museum-style environment and the Antizionism room retains its music file.
