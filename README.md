# STOPAZ

v48 cinematic auto-opening critical exposure installation website.

Upload the full contents of this ZIP to the repository root:
- index.html
- README.md
- assets folder

Built from the locked brief:
- critical documentary / anti-hate archive framing
- no generated images
- supplied archival/documentary images only
- bright gallery space contaminated by projections, torn fragments, graffiti residue, and moving light
- homepage opening timing:
  - Jew-Hatred forms in 4 seconds
  - Antijudaism / Antisemitism / Antizionism appear after that, 2.5 seconds each
- visible Music control with animated bars
- music attempts to start on first click, move, wheel, keypress, or touch
- Antizionism page is an immersive three-bay installation wall
- visible Antizionism-page labels only: Soviet, Arab, Western
- large overlapping image panels
- projections / fragments / archival residues behind and around panels
- strong hover expansion
- other bays dim and move away on hover
- cursor-responsive image parallax
- click opens large image detail view
- mobile stacks bays vertically and uses tap-to-open detail

No captions, factual text, subtitles, or new labels were added.
No live browser test was performed here.
